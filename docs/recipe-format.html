Recipe file format

A recipe is a saved set of image-control settings for the GR IIIx. This describes a plain-text file, RECIPES.TXT, that holds a library of them, and the offline checker tools/recipes.py.

The file is not installed on the camera and needs no firmware change. It is a reference you keep on a phone or computer: the checker prints each recipe as a dial-in list for the in-camera RAW development screen (playback → RAW Development), or for the two Custom image-control slots that the Wi-Fi API can switch between. The values and the rules come from the firmware (see Firmware modification: feasibility §4.3-4.4).

File layout

  • UTF-8 text in the card root, named RECIPES.TXT.
  • First non-blank line: format 1.
  • Each recipe is a [Name] header followed by key = value lines.
  • # starts a comment. Blank lines are ignored. Names are case-insensitive for keys and values; recipe names keep their case.
  • A setting that is left out is simply not dialled in; it is not forced to 0.
  • At most 32 recipes; names at most 16 characters (one screen line).
# GR recipes, format 1
format 1

[Warm Slide]
control = positive_film
saturation = +1
hue = -1
contrast = +1
contrast_highlight = -1
shading = -1
clarity = +1

[Street Mono]
control = hard_monotone
key = -1
contrast = +2
toning = sepia
grain = 2

Keys

control is required. Its value is one of:

standard, vivid, monotone, soft_monotone, hard_monotone, hi_contrast_bw, negative_film, positive_film, bleach_bypass, retro, hdr_tone, cross_process.

Key Values Notes
saturation, hue, key, contrast, contrast_highlight, contrast_shadow, sharpness, shading, clarity -4..+4 nine steps
toning monotone controls: none, sepia, red, green, blue, purple; bleach bypass / retro / HDR tone: none, 1, 2, 3; cross process: basic, magenta, yellow meaning depends on the control
filter none, 1, 2, 3, 4, custom monotone family only
grain 0..3 0 = off
hdr_strength 0..3 HDR Tone only

Each control supports only some parameters. The checker rejects a parameter the control does not have (for example saturation on a monotone control, or clarity on Soft Monotone). The supported sets follow the camera's capability table (feasibility doc §4.4).

Checking a file

python3 tools/recipes.py RECIPES.TXT
  • On success it prints every recipe as a dial-in list and exits 0.
  • On a mistake it prints each problem with the recipe name and exits 1, for example Street Mono: Contrast +9 out of range (-4..+4).

White balance is not part of a recipe: the camera keeps it outside the image-control settings. A later format version could add it.
