# Ricoh Recipes: the free GR III / GR IIIx recipes
#
# From Ritchie Roesch's ricohrecipes.com collection pages. Recipes there that
#   are only for patrons in the Ricoh Recipes app are not included.
# Read on 2026-11-20. Values as published, not checked on a camera.
#
# How the published values were turned into settings:
# - An exposure range ("-1/3 to +1/3") becomes its middle, rounded toward 0 to a
#   third of a stop; the note keeps the range as published.
# - "ISO up to 6400" is iso_max (the auto-ISO upper limit); a single ISO is iso.
# - "Medium" is mid. A setting the page leaves out stays out of the recipe.
# - Values the GR IIIx firmware has no setting for are left out; the note says so.
# Check: python3 tools/recipes.py recipes/ricoh-recipes.txt

format 2
