# GR Blog and others: Negative Film settings and a Kodak Portra recipe
#
# From Ricoh's GR Blog (grblog.jp) and a recipe gist.
# Read on 2026-11-20. Values as published, not checked on a camera.
#
# How the published values were turned into settings:
# - An exposure range ("-1/3 to +1/3") becomes its middle, rounded toward 0 to a
#   third of a stop; the note keeps the range as published.
# - "ISO up to 6400" is iso_max (the auto-ISO upper limit); a single ISO is iso.
# - "Medium" is mid. A setting the page leaves out stays out of the recipe.
# - Values the GR IIIx firmware has no setting for are left out; the note says so.
# Check: python3 tools/recipes.py recipes/gr-blog.txt

format 2

[Negative Film (factory)]
control = negative_film
saturation = 0
hue = 0
key = +2
contrast = 0
contrast_highlight = 0
contrast_shadow = -1
sharpness = 0
shading = 0
clarity = 0
author = Ricoh (OKUBO, product planner)
source = https://www.grblog.jp/en/article/6509/
note = Ricoh's own Negative Film settings as listed on the GR Blog; white balance and shooting settings not given.

contrast_shadow = -4
sharpness = 0

author = Asakura (GR Blog)
